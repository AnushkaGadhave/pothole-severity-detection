01 / CAPABILITIES

From road imagery to structured inspection cues.

CrackSight explores how computer vision and image-derived features can support preliminary pothole analysis while keeping the limitations of the available data explicit.

CAPABILITY 01

RGB pothole segmentation

An experimental multi-scale pixel classifier predicts a binary pothole-region mask directly from RGB image appearance.

CAPABILITY 02

2D geometry analysis

Image-region geometry (area footprint, aspect ratio, circularity) can be examined using the predicted 2D mask.

CAPABILITY 03

Depth-map-derived features

The feature pipeline can incorporate available dataset depth-map information where paired sensor data exists.

CAPABILITY 04

Provisional severity tiers

Relative categories are derived using the project’s current formula-based method for comparison and research.

FEATURE A · REGION DETECTION

Start with the visible surface.

The experimental RGB segmentation model estimates a pothole region from image appearance. Its predicted mask provides a basis for examining the visible region, but may also be affected by shadows, stains, and other similar-looking surfaces.

  • Multi-scale color contrast, luminance, and texture gradient features
  • Morphological refinement with 3×3 binary closing and hole-filling
  • Evaluated on strictly disjoint physical pothole groups to prevent leakage

FEATURE B · MORPHOLOGY & GEOMETRY

Turn the region into measurable image features.

The project examines two-dimensional region geometry and features derived from the available dataset. Their interpretation depends on the input data and does not automatically translate into calibrated physical measurements.

  • 14 distinct planar footprint descriptors extracted without depth requirements
  • Normalized circularity, aspect ratio, and perimeter irregularity
  • Image pixel units are kept strictly separated from physical millimeters

Make the reasoning visible.

Constituent Formula Pipeline RESEARCH SPECIFICATION
RPHI = w1·Irel + w2·Amask + w3·Vproxy
  • Irel — Relative maximum depression intensity proxy within basin.
  • Amask — Projected 2D binary surface footprint pixel area.
  • Vproxy — Integrated relative intensity volume displacement proxy.
  • w1, 2, 3 — Calibrated weights (0.40, 0.35, 0.25) fitted strictly on training group folds.

04 / SCIENTIFIC INTEGRITY

Useful signals. Honest boundaries.

Civil engineering inspection demands strict transparency regarding sensor calibration and algorithmic boundaries. CrackSight communicates its exact operational parameters:

1. Experimental RGB Segmentation

The RGB segmentation model is experimental and may confuse potholes with shadows, stains, moisture patches, or other visually similar dark road surfaces.

2. Uncalibrated Depth Maps

The dataset’s depth maps are uncalibrated 8-bit grayscale representations [0, 190] and do not establish physical depth in millimetres or calibrated volume in litres.

3. No Physical Depth from RGB

RGB segmentation alone produces a 2D planar footprint mask; it does NOT estimate 3D depth, vertical cavity profile, or volume from RGB imagery.

4. Provisional Relative Tiers

Formula-derived severity tiers (Low, Medium, High) are provisional relative percentiles within the Pothole440 dataset population, NOT certified municipal maintenance ratings.

5. Real-World Civic Deployment Preconditions

Real-world deployment would require independent geotechnical field validation, verified sensor camera geometry, calibrated focal parameters, and municipal engineering alignment (e.g., IRC:82 or BMC standards).
